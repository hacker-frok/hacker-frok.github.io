# 帮助文档（安装版）

本页面仅面向安装包用户，不涉及源码部署与开发环境搭建。

## 下载与安装

1. 打开发布页下载最新安装包：`QQFarmCVHelper_<tag>_x64_setup.exe`
2. 运行安装包完成安装。
3. 安装后使用桌面快捷方式启动程序（若被安全软件拦截，请手动放行）。
4. 打开程序后点击“开始运行”。

发布页：

- [https://github.com/hacker-frok/qq-farm-bot-ai/releases/latest](https://github.com/hacker-frok/qq-farm-bot-ai/releases/latest)

## 运行要求

- Windows 10 / Windows 11

## 核心功能

- 支持 QQ / 微信平台
- 支持隐藏小程序窗口（沉浸式运行）
- 一键收获 / 除草 / 除虫 / 浇水
- 自动买种、自动播种、自动施肥
- 收获后自动触发播种
- 好友偷取、好友帮忙、好友黑名单
- 每日任务 / 每日分享 / 商城福利 / QQ SVIP 领取
- 调度时间可自定义
- 好友流程冷却机制，避免无效空转
- “下次再来”/“重新连接”检测与自动恢复
- 周期重启、休息时段暂停、每日计数持久化
- 模板命中区域调试预览
- 全局退出热键：`Ctrl + Shift + E`
- 多开支持（多窗口、多账号）

## 建议设置（安装版用户）

1. 首次运行先用默认配置，观察 10~20 分钟稳定性。
2. 低性能设备（虚拟机/云电脑）先调大任务间隔，减少漏检弹窗。
3. 微信平台建议先不开“隐藏小程序”，确认稳定后再尝试开启。
4. 长时运行建议开启周期重启策略。

## 更新与升级

1. 从发布页下载最新安装包。
2. 安装新版前关闭正在运行的程序。
3. 安装后启动程序，检查关键开关（平台、隐藏小程序、任务间隔）是否符合预期。
